# The robot puppeteer (follow-up test)

Artem's idea: show the AI as a humanoid robot that pulls the world's strings with its own iron hands. In his words, a cloud pulling strings is a bit illogical. His first version hung the robot upside down from above, feet to the north, so only its head and arms come down into the frame; later he widened it to any framing. Sheet: [`hanging-bot.png`](hanging-bot.png). Icons: `hanging-bot/`. Source: `scripts/brand/hanging_bot.py` (run A), `robot_variants.py` (run B), `hanging_sheet.py`. Same palette and craft as the approved mark.

## Method (as in the clean rerun, [`scores3.md`](scores3.md))

- **Single-mark scoring:** each judge saw ONE mark only, as icon + "Almighty". Each mark had 7 fresh judges, each a `claude -p` session in an empty directory. Each judge scored clarity (name + icon say what the mod does), click and look from 1 to 10, plus one line on what the mod does. The approved halo cloud was scored again in each run as the control.
- **Pair test:** 3 fresh judges compared the best new variant with the approved halo cloud side by side. The labels A and B were randomized. The question: "Which one says 'an almighty AI in Minecraft' better at a glance?"

## Honest result

- **Score alone:** the approved halo cloud stays first in both runs (5.86 each time). In run B the haloed robot puppeteer is close behind at 5.71, within the noise between judges (about one point). The robot hanging with the bar follows at 5.57.
- **Meaning:** the robot changes what people read. The cloud reads as "god or admin powers… divine control over the world". The robots read as "an all-powerful **robot or overseer** that controls or edits the world". That is closer to "an AI", and in run B no judge called it automation only.
- **Head to head,** the haloed robot beat the halo cloud 2 to 1: "the robot head is clearly visible with a halo, so 'AI' and 'almighty' both read at once; in the cloud the robot is half hidden". The third judge preferred the cloud as "more clearly divine" and called the robot's bar and arms busy.
- **What did not work:** the upside-down hanging (run A) went unnoticed and scored lowest. A small player on strings read as "a robot on a pedestal / turret", and the close framing with big fists read as "machines with beams".

In short, the approved mark is not beaten on score. The **haloed robot puppeteer** (robot-bar-halo) is its equal, and it says "AI" more plainly. If Artem prefers the more literal "AI" reading and the logic of a robot that pulls the strings with its own hands, it is a sound alternative. Its weak point is a busier silhouette (the bar and arms). Artem decides; the approved package stays as it is until then.
