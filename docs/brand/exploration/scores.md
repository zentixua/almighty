# Blind scoring pool (round eight)

Sheet: [`scores.png`](scores.png). The marks are ranked by average score, each shown as icon + "Almighty". Single icons: `scores/NN-name-64.png`. Source: `scripts/brand/round8.py` (new marks), `scores_sheet.py`.

## 1. Concept thinking

**What "Almighty" already says:** all-powerful, godlike, able to do anything. The word carries the power, so the icon does not need a crown, lightning or a throne.

**What the icon must add:** (1) that it is an AI or agent, not a player or a magic item; (2) that it lives in Minecraft; (3) ideally, that the owner is in charge.

**Rule:** one simple, bold idea per mark, readable at 64 px next to the name.

About 20 ideas were noted, without reworking earlier rounds:
- a cursor with a halo
- a robot head with a halo
- the owner's palm holding the agent
- a god-mode toggle switch with the agent as its knob
- a machine eye rising over the world
- the creation touch (an AI finger and a player finger)
- a lead tied as an infinity sign
- a power-button grass block
- a key in a robot head
- a robot sun over the world
- an owner's hand holding the leash of a halo
- a crown made of cursors
- a halo on a command block
- a robot face as a block's texture
- a pickaxe gripped by a cursor
- a player silhouette with a glowing cursor heart
- the world in a snow globe held by a robot hand
- an AI "spark" in a lantern
- a crowned cursor
- a halo over a player head

Six were drawn at 64 px with full craft: the cursor with a halo, the robot head with a halo, the palm, the switch, the eye rising, and the creation touch.

## 2. Method

- **Pool:** 11 marks, unlabeled, all at the same size (64 px). The 6 new marks and the 5 earlier finalists: cloud on strings with the small visor, block head, living command block, puppeteer, monogram A. The cloud stays exactly as Artem last saw it: narrowing it would have favoured an old entry.
- **What judges saw:** each mark only as icon + the word "Almighty", as a name line in a store list. No description.
- **Judges:** 7, each a fresh `claude -p` session in an empty directory that saw only its own sheet. Each judge had a different random order.
- **Prompt:** "You are an ordinary Minecraft player scrolling a feed of mods. You see only each mod's NAME and ICON … For EACH number give three scores from 1 to 10: (a) how clearly the name plus this icon tell you what the mod does; (b) how much you would want to click it; (c) how professional it looks. Also write one short line on what you think the mod does."
- **Score:** the mean of (a), (b) and (c), averaged over the 7 judges.

## 4. What it means

- **The winner is new.** The cursor with a halo leads on clarity (6.71) and is the only mark that scored 8/8 from any judge. Judges read it as "god-like creative world editing or admin powers": the power and the game come through.
- **The earlier cloud on strings is a close second** (6.62). It ties the winner on click (7.00), has the best look score (7.00), and is lower on clarity (5.86, "sky islands / world control").
- **The halo bot is third** (6.10). It is the only mark that judges consistently read as an AI: "an all-powerful AI helper or admin assistant", in 6 of 7 reads.
- **No mark carries the whole idea by name + icon alone.** "AI" comes through only with the robot head (halo bot). "Power over the world" comes through with the halo cursor and the cloud. "The owner's control" did not come through in any mark: the palm and the switch were not read that way.
- **The earlier block head (Artem's round-five favourite) ranks 8th** (4.81). Judges read it as "computers, automation or a machine mod".

Possible next step, not done here because the brief asked for an honest ranking, not another round: join the top two cues, the agent's face (the halo bot) acting on the world (the halo cursor or the cloud). For example, a cursor whose arrow carries the agent's small visor, with a halo, over a grass block.
