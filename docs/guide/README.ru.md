# Руководство по Almighty

[English](README.md) · Русский

Almighty позволяет ИИ-агенту быть ведущим на вашем сервере Minecraft в пределах прав, которые вы задаёте. Это
руководство для владельцев серверов и для тех, кто подключает агентов. Начните с [Первых шагов](getting-started.ru.md).
