# Команды

[English](commands.md) · Русский

`<…>` — обязательно, `[…]` — по желанию. «Консоль» включает RCON.

## Для всех игроков

| Команда | Что делает |
|---|---|
| `/gm <text>` | Личное сообщение ведущему. Другие игроки и операторы его не видят. |
| `/gm @<agent> <text>` | То же одному агенту, когда подключено несколько. |
| `/almighty whoami` | Ваш UUID, считает ли сервер его проверенным, и ваша роль. |
| `/almighty confirm <id>`, `/almighty deny <id>` | Ответить на подтверждение, которое у вас запросил сервер. Щелчок по `[Allow]` или `[Deny]` в чате набирает их за вас; ответить может только тот игрок, которого спросили. |
| `/almighty undo <change>` | Откатить изменение, которое ведущий сделал по вашей просьбе. В квитанции в чате есть кнопка `[Undo]`. |

Игроки могут обращаться к ведущему и в общем чате по его имени (`feed.names`); смотрите
[Режим ведущего](game-master.ru.md).

## Для админов

| Команда | Кто | Что делает |
|---|---|---|
| `/almighty inbox` | Обладатели `almighty.approve`, консоль | Просьбы сверх прав игрока, которые ждут админа (`ask_admin`), с `[Allow]` и `[Deny]`. |
| `/almighty role <player> <role> [duration]` | Админы, консоль | Дать роль (`guest`, `member`, `builder`, `admin`) ниже своей, например `/almighty role Alex builder 3h` (`30m`, `2d`, `1h30m`). Без срока — пока роль не снимут. |
| `/almighty role <player> clear` | Админы, консоль | Снять выданную роль. |

## Для операторов уровня 4 и консоли

| Команда | Что делает |
|---|---|
| `/almighty connect` | MCP-адрес сервера, строка, чтобы добавить его в каждом приложении, и ссылки для приложений, у которых есть ссылки установки. |
| `/almighty approve` | Список ожидающих входов (приложение и адрес, но не код). |
| `/almighty approve <code> [<name>] [owner]` | Подтвердить вход, на странице которого этот код, по желанию под выбранным вами именем; `owner` даёт приложению ваши права как его потолок ([права](permissions.ru.md#ваше-приложение)). |
| `/almighty deny <code>` | Отклонить ожидающий вход. |
| `/almighty agents` | Все агенты с последним обращением и адресом. |
| `/almighty reload` | Перечитать `policy.toml` и файлы токенов агентов. Файл с ошибкой отклоняется, и прежняя политика остаётся. |
| `/almighty pause [agent]` | Красная кнопка: этот агент или все агенты могут только смотреть. Их постройки ждут, боты останавливаются, правила, созданные ниже владельца, перестают работать. |
| `/almighty resume [agent]` | Снять паузу. |
| `/almighty log [agent] [count]` | Последние записи журнала аудита (по умолчанию 10, до 100). |
| `/almighty undo <change>` | Откатить любое изменение; агент перечисляет их методом `changes`. Места, изменённые с тех пор, остаются как есть. |

## Для владельцев

Для этих команд нужна консоль или проверенный владелец из `policy.toml`, который к тому же оператор уровня 4.

| Команда | Что делает |
|---|---|
| `/almighty owner add <player>`, `/almighty owner remove <player>` | Изменить `owners` в `policy.toml`. Игрок должен хотя бы раз зайти на сервер. |
| `/almighty agent add <name>` | Новый агент с токеном в `config/almighty/agents/<name>.token`, для скриптов и CI ([без браузера](connect/headless.ru.md)). Токен никогда не выводится. |
| `/almighty agent remove <name>` | Отключить агента: его токен сразу перестаёт работать. |
| `/almighty revoke <name>` | Заменить токен агента; старый сразу перестаёт работать. |
| `/almighty script approve <name>` | Разрешить агентам с `almighty.scripts.run` запускать `config/almighty/scripts/<name>.groovy` по имени, пока файл не изменится. |
| `/almighty script revoke <name>`, `/almighty script list` | Отозвать одобрение; список одобренных скриптов. |
| `/almighty policy undo` | Вернуть `policy.toml`, сохранённый перед последним изменением. |
