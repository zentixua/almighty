# Настройки

## `config/almighty-common.toml`

Создаётся с комментариями при первом запуске. Правьте его, пока сервер остановлен, или перезапустите сервер после
правки: часть настроек применяется сразу, но настройки моста и имена в чате читаются только при запуске сервера. На
Fabric файл с ошибкой оставляет текущие настройки, а лог называет ключ.

| Ключ | По умолчанию | Что это |
|---|---|---|
| `bridge.enabled` | `true` | Запускать мост (HTTP-сервер, к которому подключаются агенты) на выделенном сервере. |
| `bridge.host` | `"127.0.0.1"` | Адрес, который слушает мост. Оставьте петлю или сеть, куда есть доступ только с машины сервера, например адрес контейнера Docker, чей порт не опубликован ([Хостинг](hosting.ru.md)). |
| `bridge.port` | `25650` | Порт моста. |
| `bridge.allowed_origins` | `[]` | Источники браузера, которым можно обращаться к мосту, например `"https://example.org"`. Запросы других веб-страниц отклоняются; агенты источник не передают. |
| `bridge.public_url` | `""` | Публичный адрес HTTPS, когда обратный прокси или туннель выводит мост в интернет, например `"https://mc.example.org"`. Его используют страницы входа и `/almighty connect`. |
| `bridge.tls_cert` | `""` | Ваша цепочка сертификатов (PEM, например `fullchain.pem`), путь от папки сервера. Вместе с `tls_key` мост говорит только по HTTPS. |
| `bridge.tls_key` | `""` | Подходящий к нему незашифрованный закрытый ключ PKCS#8 (PEM, `BEGIN PRIVATE KEY`). |
| `bridge.allow_plain_http_off_loopback` | `false` | Без TLS мост запускается только на петле. `true` запускает его без TLS на другом `bridge.host`, для сети, куда достаёт только машина сервера (частный адрес контейнера, порт которого не опубликован). Никогда на публичном адресе. |
| `bridge.integrated` | `false` | Запускать мост и в мирах одиночной игры и LAN, только на петле. |
| `work.ms_per_tick` | `3.0` | Время на тик сервера для построек, откатов, картинок и других обращений к миру, в мс (от 0,5 до 20). Когда сервер лагает, ведущий получает четверть этого времени, пока сервер не оправится. |
| `work.build_max_blocks` | `2000000` | Наибольшее число мест блоков в одной постройке. |
| `work.max_chunks` | `1500` | Наибольшее число чанков, которые ведущий держит загруженными сразу для построек и подготовленных районов, вместе с кольцом соседних чанков. |
| `feed.lag_ms` | `1000` | Записывать событие `lag`, когда между двумя тиками прошло больше стольких мс. |
| `feed.names` | `[]` | Слова, которыми к ведущему обращаются в общем чате (в любом регистре; растянутые буквы не мешают). Пусто: его `name`. |
| `feed.typo_names` | `[]` | Более длинные имена, которые узнаются и с одной опечаткой (первая буква точно). Берите только имена, которые не отличаются одной буквой от настоящего слова. Пусто: таких нет. |
| `feed.gm_messages` | `20` | Сколько сообщений в час один игрок может адресовать ведущему; на следующие сервер отвечает «Слишком много сообщений ведущему; попробуйте позже.», и до агента они не доходят. |
| `feed.default_agent` | `"gm"` | Агент, который получает сообщения, адресованные ведущему, пока он работает (обращался к серверу за последнюю минуту). Иначе их получает работающее собственное приложение владельца (агент с потолком `owner`); `/gm @<агент> <текст>` выбирает другого. |
| `feed.away_seconds` | `30` | Если агент не прочитал сообщение за столько секунд, сервер сообщает игроку, что ведущего нет на месте (сообщение сохраняется). |
| `audit.days` | `30` | Сколько дней журнала аудита хранится в `logs/almighty/`. |
| `scripts.enabled` | `true` | Скрипты Groovy и правила со скриптом. Если выключено, отклоняется и то и другое, а сохранённые правила со скриптом остаются в файле, но не загружаются. |
| `bots.max` | `8` | Наибольшее число ботов на сервере сразу. Бот нагружает сервер так же, как игрок. |
| `bots.marker` | `"[bot]"` | Пометка перед именем бота в табе и в чате. Пусто: без пометки. |
| `bots.allow_disguise` | `false` | Разрешить бота без пометки или с именем или скином игрока, которого сервер знает. У бота остаётся свой UUID, и имя он уступает, когда этот игрок заходит. |
| `name` | `"Claude"` | Имя ведущего в чате и в качестве источника его команд. |

## Файлы Almighty

| Путь | Что там |
|---|---|
| `config/almighty/policy.toml` | Кто что может ([Права](permissions.ru.md)). |
| `config/almighty/policy.history/` | Прежние версии `policy.toml` (хранятся 50). |
| `config/almighty/token` | Токен агента `gm`. |
| `config/almighty/agents/<имя>.token` | По токену на каждого другого агента. Токен — 32 случайных байта в hex; в Linux и macOS файл читает только его владелец. Токены никогда не выводятся и не пишутся в лог. |
| `config/almighty/oauth/` | Вошедшие приложения и хеши их токенов обновления. |
| `config/almighty/roles.json` | Роли, выданные командой `/almighty role`. |
| `config/almighty/notes/` | Ваши памятки для всех агентов (`server:<имя>`), в Markdown. Ведущий пишет их, только когда об этом просите вы. |
| `config/almighty/scripts/` | Скрипты, которые вы одобряете для запуска по имени; `approved.json` хранит их хеши. |
| `<мир>/almighty/rules.json` | Правила, сохранённые с миром. |
| `<мир>/almighty/notes/` | Памятки мира, которые пишут агенты (`world:<имя>`). |
| `<мир>/almighty/changes/` | Журнал изменений: каждый блок, который записал ведущий, для отката. До 4 миллионов мест и 1000 изменений. |
| `logs/almighty/audit-<дата>.jsonl` | По строке на каждый вызов, который что-то изменил, и на каждый отказ. |

Сохраняйте `config/almighty/` в резервной копии вместе с сервером; кто может прочитать файл токена, тот управляет
сервером.
