# Подключение агента

[English](README.md) · Русский

Сервер говорит на MCP по адресу `http://<адрес>:25650/mcp` (с той же машины: `http://127.0.0.1:25650/mcp`). Любое
приложение ниже может добавить его само, если попросить простыми словами («подключись к моему серверу Minecraft
(Almighty) по адресу ...»); на каждой странице есть и одна строка, чтобы сделать это самому. Ключ или токен не нужен:
приложению, которое обратилось по адресу без входа, сервер так и отвечает и называет команды, подключающие Claude
Code и Codex. Вход везде одинаковый: приложение открывает страницу с четырёхзначным кодом, и вы набираете
`/almighty approve <код>` в консоли сервера или, как владелец, в игре. На сервере, у которого ещё нет владельца,
первый оператор уровня 4, подтвердивший вход в игре, становится его владельцем
([Первые шаги](../getting-started.ru.md#3-подтвердите-вход-кодом)).

`/almighty connect` в консоли (или в игре, как оператор) выводит адрес, эти строки и ссылки для приложений, у которых
есть ссылки установки.

Тем, у кого ChatGPT: пользуйтесь **приложением ChatGPT для компьютера в режиме Codex** (оно запускает Codex на вашем
компьютере и входит в любой план ChatGPT). ChatGPT в браузере подключается с серверов OpenAI, поэтому ему нужен
ваш сервер на публичном адресе HTTPS; смотрите [cloud.ru.md](cloud.ru.md).

Маленькие локальные модели: добавьте к адресу `?profile=compact&images=false`, чтобы получить 6 коротких
инструментов и обойтись без картинок.
