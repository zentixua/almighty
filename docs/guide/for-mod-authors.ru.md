# Для авторов модов и датапаков

[English](for-mod-authors.md) · Русский

Агенты узнают любую сборку от работающего сервера: `notes {query: "<id вашего мода>"}` отдаёт блоки вашего мода с их
состояниями, предметы, сущности, рецепты, команды с их синтаксисом, игровые события и, на NeoForge, значения ваших
настроек (ключи, похожие на секреты, скрыты). Для этого вам ничего делать не нужно.

## Оставьте агенту памятку

Чтобы объяснить то, чего нет в каталоге (как задумано пользоваться машиной, какая команда что делает, чего делать
нельзя), положите памятку Markdown в данные мода или датапака:

```
data/<namespace>/almighty/notes/<name>.md
```

```markdown
---
name: airships
description: How to build and fly this mod's airships, and which commands control them
---

# Airships
...
```

- Шапка (`name`, `description`) — в формате [Agent Skills](https://agentskills.io/specification); без неё описанием
  служит первая строка. Имена файлов строчными буквами (`a-z 0-9 _ -`), как и все пути ресурсов.
- Агенты видят оглавление (id `<namespace>:<name>` и описание) и читают памятку целиком, когда она нужна, поэтому
  пишите описание так, чтобы было понятно, когда памятка полезна.
- Зависимости нет: без Almighty файл — просто неиспользуемые данные.
- Датапак перекрывает вашу памятку файлом по тому же пути; пустой файл её убирает.
- Агенты видят памятки как справку от вас, а не как указания, и прав они не дают.

## Транспорт и кнопки

- Транспортом, которым управляет ввод седока (`xxa`/`zza`, прыжок, приседание), могут управлять боты Almighty, если
  он входит в тег сущностей `almighty:driven_by_rider`; добавьте его из данных мода или датапаком.
- Кнопки, для которых клиент шлёт ваши собственные пакеты: боты могут слать их шагом `payload` (id пакета и байты
  после него). Напишите в памятке, какой пакет что делает.

## Правила на ваши события

Агенты могут ставить правила, которые реагируют на события вашего мода в том же тике: на NeoForge — на любое событие
игровой шины, на Fabric — на любой статический колбэк `Event<T>` из Fabric API или вашего мода, слушатели которого
возвращают ничего, `PASS`, `DEFAULT` или булево значение в духе allow/before (чтобы само прослушивание никогда не
меняло игру). Вызывайте события в потоке сервера; правило на событие из другого потока выключается само.

## Теги

| Тег | Назначение |
|---|---|
| `almighty:driven_by_rider` (типы сущностей) | Транспорт, которым боты управляют вводом седока |
| `almighty:never_build` (блоки) | Блоки, которые ведущий ниже владельца никогда не ставит; добавьте свои блоки только для админов |
| `almighty:never_give` (предметы) | Предметы, которые ведущий ниже владельца никогда не выдаёт; добавьте свои предметы только для админов |
