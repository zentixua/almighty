# Режим ведущего

[English](game-master.md) · Русский

Подключённый агент отвечает вам. Чтобы он отвечал игрокам, как только они пишут, он должен работать без остановки и
следить за лентой событий сервера. В каждом приложении свой способ держать сессию запущенной; со стороны сервера всё
одинаково: инструмент `events` ждёт новых событий до 25 секунд и возвращает их.

## Как игроки обращаются к ведущему

- **`/gm <текст>`** — личное сообщение ведущему. Игрок видит его как «Ведущему: <текст>»; другие игроки и операторы его
  не видят, и агент может ответить только этому игроку. Если агентов несколько, `/gm @<агент> <текст>` выбирает одного.
- **Его имя в общем чате** (`name` или слова из `feed.names`) тоже обращается к нему, даже с растянутыми буквами,
  а для имён из `feed.typo_names` и с одной опечаткой.
- **Разговор** остаётся открытым 3 минуты после того, как игрок обратился к ведущему или получил ответ: его строки
  доходят до ведущего без имени.
- **Игрок, который один на сервере**, обращается к нему любой строкой чата.

Сообщения получает агент из `feed.default_agent` (по умолчанию `gm`), пока он работает; иначе — ваше собственное
приложение (подтверждённое с `owner`), пока работает оно. Чтобы только что подключённое ваше приложение слышало
игроков, ничего настраивать не нужно. Каждому вошедшему игроку сообщают, что ИИ-ведущий читает общий чат и действует
по обращённым к нему сообщениям (`[safety] privacy_notice`).

Агент слышит только игроков, которым доверено то, что он может делать без просьбы: на закрытом сервере только
владельцев, на сервере друзей проверенных игроков, на публичном всех
([Кого слышит агент](permissions.ru.md#кого-слышит-агент)).

Что обращено к ведущему, решает сервер, а не агент. Каждый игрок может обратиться к ведущему 20 раз в час
(`feed.gm_messages`); сверх этого сервер отвечает «Слишком много сообщений ведущему; попробуйте позже.». Если агент
не прочитал сообщение `/gm` или строку с его именем за 30 секунд (`feed.away_seconds`) или минуту ничего не вызывал,
сервер говорит игроку, что ведущего сейчас нет; сообщение сохраняется. Если этот агент отсутствует дольше минуты,
а игроков теперь направляют к другому приложению (например, к вашему собственному, пока `gm` остановлен), это
приложение получает сохранённые сообщения, до 10 минут, кроме сообщений, адресованных конкретному агенту через
`/gm @<агент>`, и сообщений игроков, которым новое приложение недоступно. Пока вы держите его на паузе
(`/almighty pause`), сервер отвечает «Владелец сервера приостановил ведущего; ваше сообщение сохранено.» Эти строки
идут на языке игры игрока: на русском для `ru_ru`, иначе на английском.

Каждое обращённое сообщение несёт тикет. Когда агент действует по нему (каждый инструмент принимает его как `for`), вызов выполняется с правами этого игрока
([Права](permissions.ru.md)), а всё, что затрагивает других, ждёт подтверждения игрока. Каждый инструмент
принимает и короткое описание `summary` своими словами агента; игроки видят его в кавычках рядом с тем, что сервер
сам говорит о выполняемом.

## Держите агента запущенным

С чего начать в любом приложении:

```
Ты ведущий на моём сервере Minecraft (Almighty). Сначала прочитай notes {id: "almighty:game_master"}.
Потом по кругу: жди событий через events {after, wait: 25}; отвечай игрокам, которые пишут тебе (события gm
или чат, где тебя называют по имени), через say {to}; передавай next как следующий after. Продолжай, пока я тебя не остановлю.
```

| Приложение | Как держать его запущенным |
|---|---|
| Claude Code | Запустите этот запрос в сессии; `/loop` сам повторяет запрос. Чтобы игроки будили сессию, как только пишут, есть канал чата в [`mcp/gm`](../../mcp/gm/README.md) (на английском; плагин Claude Code, по желанию). |
| Codex, приложение ChatGPT для компьютера (режим Codex) | Запустите запрос в сессии или `codex exec "<запрос>"` из скрипта или службы, чтобы ведущий работал без присмотра. |
| Другие | Запустите запрос; большинство приложений держат долгую задачу, пока она вызывает инструменты. |

## Память

Всё, что ведущий должен помнить между сессиями, храните в памятках мира (`notes {id: "world:<имя>", text}`): они
лежат вместе с миром, и их прочитает любая следующая сессия или другое приложение. Сервер записывает, кто написал
каждую памятку и для кого. Его собственный стиль и ваши пожелания храните в памяти приложения (Claude Code:
`CLAUDE.md`; Codex: `AGENTS.md`). Ваши собственные памятки для всех агентов кладите в
`config/almighty/notes/<имя>.md`; ведущий пишет их туда, когда об этом просите вы, владелец.
