# Если что-то не работает

[English](troubleshooting.md) · Русский

## Установка и подключение

| Что вы видите | Что делать |
|---|---|
| Сервер не запускается и называет Almighty | Проверьте, что jar подходит к версии Minecraft и загрузчику сервера, и проверьте версию Java ([требования](getting-started.ru.md#1-установите-мод)). На Fabric установите Fabric API (0.155.3 или новее на 26.1.2, 0.167.0 или новее на 26.3). |
| В консоли нет строки «Almighty ready» | Мост работает только на выделенном сервере, не в одиночной игре (смотрите `bridge.integrated`). Проверьте `bridge.enabled` в `config/almighty-common.toml` и поищите в логе «Almighty bridge failed to start»: часто порт 25650 уже занят, тогда поменяйте `bridge.port`. |
| Приложение не может подключиться, или соединение отклонено | Приложение запущено не на той машине, где сервер: воспользуйтесь туннелем SSH ([Хостинг](hosting.ru.md)). Проверьте, что адрес заканчивается на `/mcp`. |
| Приложение пишет, что серверу нужен вход | Начните вход (Claude Code: `/mcp` → «Authenticate»; Codex: `codex mcp login almighty`; opencode: `opencode mcp auth almighty`). |
| Страница входа пишет «Too many logins are waiting» | Уже ждут пять входов: подтвердите или отклоните их (`/almighty approve` показывает список) или подождите 10 минут. |
| `/almighty approve <код>` отвечает «No login is waiting with code …» | Код истёк (10 минут) или набран неверно: начните вход в приложении заново. |
| Страница пишет «Unknown host» | Её открыли под именем, которого сервер не знает: используйте `127.0.0.1` или укажите `bridge.public_url`. |
| Инструменты приложения не появились после добавления сервера | Начните новую сессию (Codex, Claude Code после `claude mcp add`). |
| Маленькая локальная модель путается | Добавьте `?profile=compact&images=false` ([Локальные модели](connect/local-models.ru.md)). |

## Права и отказы

| Что вы видите | Что делать |
|---|---|
| Вызов отклонён с `policy`, узлом и тем, что разрешено | У агента нет этой возможности для этого вызова. Без просьбы игрока он действует со своим полом (участник на сервере для друзей); смотрите [Права](permissions.ru.md#агенты-потолок-и-пол). |
| Ваше собственное приложение не может выполнять команды оператора и скрипты | Подтвердите его с `owner`, а затем либо просите его в игре через `/gm` как владелец, либо дайте ему `floor = "owner"` ([Ваше приложение](permissions.ru.md#ваше-приложение)). |
| На `/gm` игрока сервер отвечает «Ведущий здесь принимает просьбы только от игроков, которым доверено то, что он может делать.» | Игрок ниже пола агента: на `private` слышны только владельцы, на `friends` только проверенные игроки ([Кого слышит агент](permissions.ru.md#кого-слышит-агент)). На `private` переключитесь на `friends` или добавьте игрока во владельцы; на `friends` игрок должен быть проверен (`/almighty whoami`). |
| Ваши просьбы через `/gm` не несут прав владельца | Добавьте себя командой `/almighty owner add <имя>` в консоли; `/almighty whoami` должна показывать, что вы проверены. На сервере в режиме offline за Velocity укажите `identity = "proxy"`. |
| Вызов отклонён с `denied` | Он в списке, отклоняемом для любого агента, потому что роняет или замораживает серверы ([Безопасность](security.ru.md#что-защищает-сервер)). Если он вам действительно нужен, выполните его сами в консоли. |
| Вызов отвечает `423` | Агент на паузе: `/almighty resume [агент]`. |
| Вызов отвечает `429` | У игрока кончилась квота на час, ждёт слишком много подтверждений или просьб к админам, или адрес заблокирован после неверных токенов. |
| `policy.toml refused, the previous policy stays` | В сообщении названы ключ и ошибка; исправьте её и выполните `/almighty reload`. |

## Во время работы

| Что вы видите | Что делать |
|---|---|
| Сервер лагает, пока агент работает | Уменьшите `work.ms_per_tick`; попросите агента остановить работы (`job` с `cancel`) и правила (`rule` remove). `/almighty pause` сразу останавливает стройки, ботов, правила со скриптом и правила, созданные ниже владельца. |
| Правило перестало работать | Оно выключилось само: `rules` показывает его с причиной (бюджет времени, 10 ошибок подряд, засорение ленты). |
| Стройка ждёт и не начинается | Её чанки ещё не загружены; она ждёт до 2 минут. Место на участке корабля Sable отклоняется. |
| Игроки получают «Ведущего сейчас нет; ваше сообщение сохранено.» | Агент не прочитал их сообщение за `feed.away_seconds`. Держите его запущенным в [режиме ведущего](game-master.ru.md). |

Всё ещё не работает: `/almighty agents` показывает, доходят ли обращения агента, `/almighty log` показывает его
последние действия и отказы, а в логе сервера видна каждая команда ведущего («GM: /...») и каждый вход. Тогда
откройте [задачу](https://github.com/zentixua/almighty/issues/new/choose).
