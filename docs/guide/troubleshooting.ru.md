# Если что-то не работает

[English](troubleshooting.md) · Русский

| Что вы видите | Что делать |
|---|---|
| В консоли нет строки «Almighty ready» | Мост работает только на выделенном сервере, не в одиночной игре. Проверьте `bridge.enabled` в `config/almighty-common.toml` и поищите в логе «Almighty bridge failed to start» (часто порт 25650 уже занят: поменяйте `bridge.port`). |
| Приложение не может подключиться, соединение отклонено | Приложение запущено не на той машине, где сервер: воспользуйтесь туннелем SSH ([Хостинг](hosting.ru.md)). Проверьте, что адрес заканчивается на `/mcp`. |
| Приложение пишет, что серверу нужен вход | Начните вход (Claude Code: `/mcp` → «Authenticate»; Codex: `codex mcp login almighty`; opencode: `opencode mcp auth almighty`). |
| Страница входа пишет «Too many logins are waiting» | Уже ждут пять входов: подтвердите или отклоните их (`/almighty approve` показывает список) или подождите 10 минут. |
| `/almighty approve <код>` отвечает «No login is waiting» | Код истёк (10 минут) или набран неверно: начните вход в приложении заново. |
| Страница пишет «Unknown host» | Её открыли под именем, которого сервер не знает: используйте `127.0.0.1` или укажите `bridge.public_url`. |
| Инструменты приложения не появились после добавления сервера | Начните новую сессию (Codex, Claude Code после `claude mcp add`). |
| Инструмент отвечает `403` или `forbidden` | Сервер отклонил вызов по списку опасных вызовов или по правам; в сообщении сказано почему и что можно. |
| Сервер лагает, пока агент работает | Уменьшите `work.ms_per_tick`; попросите агента остановить работы (`job` с `cancel`) и правила (`rule remove`). |
| Маленькая локальная модель путается | Добавьте `?profile=compact&images=false` ([Локальные модели](connect/local-models.ru.md)). |

Всё ещё не работает: `/almighty agents` показывает, доходят ли обращения агента; в логе сервера видна каждая команда
ведущего («GM: /...») и каждый вход.
