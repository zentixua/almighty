The first release under the Almighty name and in its own repository. The mod was previously called airstrike-gm (the "game master mod") and shipped in Airstrike releases; the last version under the old name was 0.1.2 (Airstrike 2.9.0).

New:

- bot players: the agent creates bots that join as ordinary players (marked "[бот]" in the tab list) and do what a player does by hand: walk, mine and build, use chests and menus, chat and respawn. Methods `bots`, `bot`, `bot.spawn`, `bot.remove`, `bot.act`, tool `bot`. A bot can take a server player's name and skin only if the owner enables `bots.allow_disguise`; it is off by default;
- vision: method `see` and the `eye` view of the `view` tool. This is what any player, bot or free camera sees: as text and, on request, an image;
- vehicles without a client: a bot drives vehicles controlled by a player (horses, donkeys, mules and camels with jumping, boats, pigs and striders with a fishing rod), and Immersive Aircraft planes: compatibility is enabled only when that mod is installed. The bot presses mod keys with the `press` step. A mod or datapack can add its own vehicles driven by rider input to the `almighty:driven_by_rider` tag. After death, a bot respawns as a bot;
- mod packets: a bot can send a mod packet on behalf of a client using its id and bytes (the `payload` step), so it can press mod buttons that send their own packets, without separate code for each mod;
- mod notes: a mod or datapack places agent instructions in `data/<namespace>/almighty/notes/<name>.md`; the adapter appends the server's notes to its instructions, with the `notes` method and tool. Airstrike strike hints now live in Airstrike's own note, rather than in the adapter.

Names have changed for server owners:

- mod id `almighty` replaces `airstrike_gm`, file `almighty-0.2.0.jar`;
- settings: `config/almighty-common.toml` (previously `config/airstrike_gm-common.toml`), token: `config/almighty/token` (previously `config/airstrike_gm/token`), world rules: `<world>/almighty/rules.json` (previously `<world>/airstrike_gm/rules.json`). These are not migrated automatically: rename the old files when updating;
- MCP adapter: `mcp/almighty.py` (previously `tools/gm.py` in zentixua/airstrike), variables `ALMIGHTY_URL`, `ALMIGHTY_TOKEN`, `ALMIGHTY_TOKEN_FILE` (previously `AIRSTRIKE_GM_*`).

## Installation

The "Airstrike Pack" modpack installs Almighty only on the server, replacing the old game master mod. Without the modpack: put `almighty-0.2.0.jar` in the server's `mods` folder instead of `airstrike-gm-*.jar` and rename the old settings, token and world rules as described above. Players install nothing. Agent connection instructions are in the [README](https://github.com/zentixua/almighty#install).
