Fixes after playing on the server on 04.10.

- The server no longer crashes when the game master builds or prepares an area at Create Aeronautics ship coordinates. Sable manages ship chunks, and the bridge no longer places its own tickets there. Building, undo, area preparation and bot login there immediately refuse with a reason. Previously, generation started in those chunks, and the server crashed with an NPE in `ChunkMap.acquireGeneration`.
- Game master sessions now have protected zones (`mcp/gm/zones.py`, next to the adapter, not included in the jar). A strike's path, including spread, is checked against them before launch; on a conflict, the script suggests a waypoint around the zone.

## Installation

The "Airstrike Pack" modpack installs Almighty only on the server. Without the modpack: replace `almighty-0.2.1.jar` in the server's `mods` folder with `almighty-0.2.2.jar`. Players install nothing.
