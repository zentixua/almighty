Ведущий надёжнее водит транспорт: правки по игре 04.10.

- У ботов появилась «мёртвая рука». Шаг `hold` принимает срок `ticks`: клавиша отпускается сама, если её не продлили. Если выключилось правило, которое вело бота (по бюджету, по ошибкам или из-за потока записей в ленту), бот останавливается: программы сняты, клавиши отпущены, в ленте событие `bot_stopped`. Раньше, когда правило автопилота самолёта Immersive Aircraft выключилось, удержанный руль остался нажатым, и самолёт ушёл в море.
- Скрипт может заменить программы бота вызовом `bot.act(шаги, true)`, как `replace` у метода `bot.act`.
- Автопилоту кораблей Sable (Create Aeronautics) стали видны сами корабли: метод `ships`, в скриптах — `gm.ship(имя)` и `gm.ships()`. Видны имя, место, поворот, скорость в блоках в секунду, угловая скорость, рамки в мире и на участке, а также блок-сущности корабля по типу (моторы, горелки). Связь идёт через открытую библиотеку Sable (sable-companion), без миксинов. Без Sable метод отвечает, что кораблей нет.

## Установка

Сборка «Airstrike Pack» ставит Almighty только на сервер. Без сборки: замените в папке `mods` сервера `almighty-0.2.2.jar` на `almighty-0.3.0.jar`. Игрокам ставить ничего не нужно.
