Stationary game master bots no longer burden the server.

- A bot recalculates which entities it can see at the same times a real client sends a movement packet to the server: when it moves, turns, lands or leaves the ground, and once every 20 ticks when stationary. Previously, every bot did this every tick, and on a map with tens of thousands of entities (item frames, paintings and armor stands in the Project Zearth city), one such recalculation costs about 10 ms. Six bots consumed more than a third of a server tick; a stationary bot now costs the server as much as a stationary player.

## Installation

The "Airstrike Pack" modpack installs Almighty only on the server. Without the modpack: replace `almighty-0.3.0.jar` in the server's `mods` folder with `almighty-0.3.1.jar`. Players install nothing.
