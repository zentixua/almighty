For Minecraft 1.21.1 and NeoForge 21.1.259 or newer. Server only: players install nothing.

## Changes

- Everything Almighty writes for the server owner and the agent is in English: the comments in `config/almighty-common.toml`, the bridge's error messages, the log lines and the tool descriptions of the MCP adapter `mcp/almighty.py`. The README is in English, with a Russian translation in `README.ru.md`.
- The minimum NeoForge version is 21.1.259 (it was 21.1.250).
- The default bot marker is `[bot]`. A config file written by 0.3.1 or earlier keeps `[бот]` until you change `bots.marker`.
- `mcp/gm` holds the kit that runs the game master as one Claude Code session: a chat channel plugin, a hook that denies the calls that have already crashed or frozen a server and asks the owner before `op`, `ban` and similar commands, and recipes. It replaces the older pipeline. The lines players see from the kit follow `GM_LANG`: English by default, `ru` for Russian.

## Installation

Replace `almighty-0.3.1.jar` in the server's `mods` folder with `almighty-0.4.0.jar`. Players need nothing. See the [README](https://github.com/zentixua/almighty#install).
