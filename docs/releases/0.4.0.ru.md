Для Minecraft 1.21.1 и NeoForge 21.1.259 или новее. Только сервер: игрокам ничего устанавливать не нужно.

## Изменения

- Всё, что Almighty пишет владельцу сервера и агенту, теперь на английском: комментарии в `config/almighty-common.toml`, ошибки моста, строки журнала и описания инструментов MCP-адаптера `mcp/almighty.py`. README — на английском, русский перевод — в `README.ru.md`.
- Минимальная версия NeoForge — 21.1.259 (была 21.1.250).
- Метка бота по умолчанию — `[bot]`. Файл настроек, созданный версией 0.3.1 или старше, сохраняет `[бот]`, пока вы не измените `bots.marker`.
- В `mcp/gm` находится набор для запуска ведущего одной сессией Claude Code: чат-плагин, хук, который запрещает вызовы, уже приводившие к падению или зависанию сервера, и спрашивает владельца перед `op`, `ban` и подобными командами, а также рецепты. Он заменяет прежний конвейер. Текст набора для игроков следует `GM_LANG`: по умолчанию английский, `ru` — русский.

## Установка

Замените `almighty-0.3.1.jar` в папке `mods` сервера на `almighty-0.4.0.jar`. Игрокам ничего не нужно. См. [README](https://github.com/zentixua/almighty/blob/main/README.ru.md#установка).
