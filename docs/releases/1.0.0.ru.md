Almighty 1.0: ИИ-ведущий для вашего сервера Minecraft — теперь для актуальных версий Minecraft и для Fabric, с
системой прав, с которой его можно доверить друзьям или публичному серверу. Только сервер: игрокам ничего ставить не
нужно.

## Файлы

Выберите jar для версии игры и загрузчика вашего сервера:

| Minecraft | NeoForge | Fabric |
|---|---|---|
| 1.21.1 | `almighty-1.0.0+1.21.1-neoforge.jar` (NeoForge 21.1.264+) | — |
| 26.1.2 | `almighty-1.0.0+26.1.2-neoforge.jar` (NeoForge 26.1.2.130+) | `almighty-1.0.0+26.1.2-fabric.jar` (Fabric Loader 0.20.1+, Fabric API) |
| 26.3 | `almighty-1.0.0+26.3-neoforge.jar` (NeoForge 26.3.0.118+) | `almighty-1.0.0+26.3-fabric.jar` (Fabric Loader 0.20.1+, Fabric API) |

Java 21 для 1.21.1, Java 25 для 26.x (как нужно самой игре).

## Любое приложение-агент без настройки

- Мод сам отвечает по MCP на `http://127.0.0.1:25650/mcp`: скажите Claude Code, Codex (в том числе в приложении
  ChatGPT для компьютера), Cursor, VS Code или другому MCP-приложению «connect to my Minecraft server at …», и оно
  добавит сервер.
- Вход — стандартный вход MCP: приложение открывает страницу с четырёхзначным кодом, вы вводите на сервере
  `/almighty approve <код>`. Ни токенов, ни файлов настроек, ни адаптера.
- `/almighty connect` показывает все способы подключения; запуски без браузера (`claude -p`, `codex exec`, CI)
  используют токен агента (`/almighty agent add <имя>`).
- Несколько агентов сразу, у каждого свой токен, присутствие (`/almighty agents`) и права. HTTPS со своим
  сертификатом (`bridge.tls_cert`, `bridge.tls_key`) или за вашим обратным прокси или туннелем (`bridge.public_url`).

## Кто что может поручить

- `config/almighty/policy.toml` выбирает набор. **Новые серверы начинают с `friends`**: говорить с ведущим может
  каждый, обычные просьбы участников выполняются сразу, всё крупнее спрашивает нужного человека одним щелчком.
  **`public`** — для серверов, открытых незнакомым. **Серверы, обновляющиеся с 0.4, остаются на `private`**, у них
  ничего не меняется.
- Просьба игрока выполняется с правами самого игрока, не больше: ведущего нельзя уговорить сделать для кого-то то,
  чего тот не может сам. Необратимое для других людей ждёт подтверждения просящего в чате; просьбы уровня админа могут
  уйти админу одной тихой сводкой.
- Каждая возможность — узел прав `almighty.<возможность>` (LuckPerms на NeoForge, на Fabric — через
  fabric-permissions-api). Без плагина прав: `/almighty role <игрок> <роль> [срок]`.
- Учитываются зоны (без стройки на спавне, своя арена), часовые лимиты и приваты Open Parties and Claims и FTB
  Chunks. Командные блоки, спавнеры, барьеры и подобное для игрока не строятся никогда; предметы получает только тот,
  кто попросил.
- Владелец может менять всё это, просто попросив ведущего; изменения, которые дают больше прав, ждут подтверждения
  владельца, а `/almighty policy undo` откатывает.

## Безопасность

- Каждый блок, изменённый ведущим, записывается на диск и отменяется, даже после падения сервера; отмена не трогает
  блоки, которые с тех пор кто-то изменил (`changes`, `/almighty undo <изменение>`).
- Каждый вызов с последствиями и каждый отказ — в журнале (`/almighty log`); `/almighty pause` — красная кнопка.
- Команды, известные тем, что роняют или вешают сервер, запрещены для всех агентов; работа ведущего не берёт больше
  своей доли тика и уступает, когда сервер тормозит.
- Команда, которую агенту нельзя выполнить на его уровне, так и отвечает (`needs_level` с подсказкой), а не
  ванильным «Unknown or incomplete command».
- Правила без кода (условия и действия) для всех ниже владельца, привязанные к тому, кто их попросил; скрипты по
  имени, одобренные владельцем.

## Изучает вашу сборку

`notes {query}` даёт агенту моды, блоки, предметы, рецепты, команды, события и настройки работающего сервера. Моды и
датапаки могут класть заметки для агентов в `data/<namespace>/almighty/notes/<name>.md`; мир хранит собственные
заметки ведущего.

## Fabric

На Fabric работает всё. Правила там реагируют на любой callback Fabric API или мода (на NeoForge — на любое
событие), ответ которого может оставаться нейтральным, пока правило только слушает, а отмена заставляет callback
вернуть своё значение «стоп». Боты на Fabric получают только ванильные пакеты
(пакеты модов требуют согласования каналов NeoForge для соединений в памяти).

## Обновление с 0.4.0

Замените `almighty-0.4.0.jar` в `mods/` на jar для своей версии и загрузчика. Ваш `policy.toml` записан с
`preset = "private"`, это сохраняет нынешнее поведение; прочтите
[Безопасность](https://github.com/zentixua/almighty/blob/main/docs/guide/security.ru.md), прежде чем переключаться на
`friends` или `public`. Адаптер `mcp/almighty.py` и набор `mcp/gm` по-прежнему работают, но больше не нужны:
подключайте приложение прямо к `/mcp`.
