# Ведущий на сервере: охраняемые зоны и проверка до слов

Инструменты сессий ведущего рядом с адаптером, без зависимостей (только Python 3). Появились после игры 04.10.2026
на Zearth: свой же удар попал в лайнер игроков, а игрокам дважды сказали «готово» раньше, чем это было правдой.

## Охраняемые зоны — `zones.py`
Зона — круг на карте (x, z, радиус в блоках), куда удары, взрывы и полёты ведущего не должны попадать: стоянка
кораблей и самолётов игроков, база, место, где игроки собрались смотреть. Файл зон — `zones.json` рядом со скриптом
(в git не идёт) или путь из `GM_ZONES`; общий для всех сессий ведущего, запись под flock.

```sh
python3 mcp/gm/zones.py add аэропорт -1650 470 250 --note "лайнер и NagaAI"   # корабль передвинули — та же команда
python3 mcp/gm/zones.py add зрители 120 -40 60 --ttl 30                         # на полчаса
python3 mcp/gm/zones.py check --from -2450 666 --to 52 118 --spread 50          # путь залпа и разброс у цели
python3 mcp/gm/zones.py check --to 300 200 --spread 20                          # только место падения
```

`check` — код 0 («можно») или 1 («НЕЛЬЗЯ» с причиной и точкой обхода `--via`; путь с ней проверить снова).
Путь — отрезки от места пуска через точки `via` к цели; у последнего отрезка запас растёт к разбросу цели,
у цели — круг разброса. Запас по умолчанию 64 блока (`--margin`): снаряды уходят с прямой на манёвр захода.

- Перед каждым ударом, залпом, кампанией и полётом с маршрутом — `check`; «НЕЛЬЗЯ» — не пускать.
- Кампания в цикле — проверка до первого пуска и после каждой новой зоны.
- Кто ставит корабль, сажает игроков или собирает их — сам добавляет зону, до того как сказать игроку.

## «Готово» — после проверки в мире
- Игроку — результат, проверенный в мире, а не запуск: транспорт в воздухе и игрок на борту — `entities` или `see`;
  постройка стоит — `view` (`blocks`); удар ушёл — лента `events` или лог мода. Не проверено — «делаю», без обещаний
  наперёд.
- Нельзя (запрет, нет механизма) — сразу и одной фразой с причиной; ответ не меняется через пять минут.
- Сервер перезапустился — `almighty.py follow` пишет `bridge_down`, `bridge_up` и `server_restarted`: после
  `server_restarted` отвечать игрокам сразу, ждать и проверять порт вручную не нужно.
