# Ведущий: голос, исполнители, наставник

Набор, который делает из моста Almighty живого ведущего сервера на Claude: игроки зовут его в чате или пишут лично
(`/gm`), он отвечает за секунды, делает их просьбы в мире, говорит «готово» только по проверке в мире и учится на
каждом разговоре. Только Python 3.11+ и `claude` (Claude Code) на сервере; модели — по подписке владельца.
Появился после игры 04.10.2026 на Zearth: из 16 сбоев того дня 12 были импровизацией без проверенных способов,
свой удар попал в лайнер игроков, а «готово» дважды прозвучало раньше, чем было правдой.

## Как устроен
```
игроки ── лента моста ──▶ диспетчер (gmd.py, без ИИ) ──▶ голос (claude -p, один живой процесс)
                              │   ▲                         │ reply — единственный, кто говорит
                              │   └── итоги задач ◀──┐      │ task — долгое исполнителю
                              ▼                      │      ▼
                         очередь (gm.db) ──▶ исполнители (свежий claude -p на задачу, ≤2)
                              │
                         опыт ──▶ наставник (claude -p в копии знаний) ──▶ ворота (gate.py) ──▶ навык
```
- **Диспетчер** (`gmd.py`) — служба: слушает ленту моста, будит голос только на сообщения ведущему (личное `/gm`;
  в чате — по имени из `gm.names`, кто говорит с ведущим — 90 с без имени), ведёт очередь задач с ресурсами и
  сроками, пишет всё в журнал: время ответа, цену, итоги.
- **Голос** — единственный, кто говорит с игроками (`reply`): отвечает, смотрит мир, делает мгновенное (рецепты
  `instant`), ставит задачи. Перезапуск в паузе — после `voice_turns` ходов и после правки навыка.
- **Исполнители** — свежая сессия на задачу: рецепт или рычаги, `progress`, конец — `done` с проверкой в мире
  (мост выполняет её сам, ответ — доказательство) или `fail`. Итог голосу, он говорит игроку.
- **Наставник** — после нового опыта (уроки сессий, ошибки, отказы охраны, брошенные задачи, молчание голоса,
  долгие ответы, каждые 8 сообщений): правит знания сервера в отдельной копии (git worktree), рецепты пробует на
  тестовом сервере. Правка входит в навык только через **ворота** (`gate.py`):
  1. порядок: только свои файлы, `evals/learned.jsonl` и `rules.local.md` — только дописать, `CORE.md` — коротко,
     каждый новый рецепт — с удачной пробой этого же текста;
  2. проверочный набор (`evals/base.jsonl` набора и `learned.jsonl` сервера): голос с новым навыком не хуже
     прежнего, случаи урока проходят;
  3. независимый рецензент — `clean`.
  Принятая правка — коммит в git каталога сервера; откат — `git revert`.
- **Охрана** (`guard.py`) — хук PreToolUse каждой сессии и проверка шагов рецептов: один голос (никаких `/say`,
  `/tellraw`, чата ботов, сообщений из скриптов у других), запреты сервера, дела только по слову владельца (чей
  запрос — по очереди, не по тексту), удары — только числами и мимо охраняемых зон, скрипты без загрузки чанков,
  потоков и задач на потом, ничего на участках кораблей Sable, наставник правит только свои файлы.

## Навык
`skill/` — навык Claude Code (`SKILL.md`, имя `gm`; его можно поставить и в обычный Claude Code):
- `SKILL.md` — ядро: как работать отлично, решение на каждое сообщение, инструменты;
- `RULES.md` — правила, которые уроки не меняют; `roles/` — голос, исполнитель, наставник, рецензент;
- `levers.md` — рычаги Almighty глубоко: что как делается и как проверить;
- `recipes/` — проверенные способы (формат — `recipes.py`): шаги — вызовы моста, проверка — Groovy в мире.
Знания сервера (каталог сервера, его git): `skill/CORE.md` (выученное, в каждом ходе голоса),
`skill/knowledge/*.md`, `skill/recipes/*.md`, `skill/rules.local.md`, `evals/learned.jsonl`. Общий опыт —
после игрового дня PR сюда (ядро, рычаги, рецепты без привязки к серверу).

Сессии чистые: свой системный промпт (роль + ядро + правила + выученное), без памяти Claude Code, без CLAUDE.md,
без чужих навыков и настроек (`--setting-sources project`, `--strict-mcp-config`, `--disable-slash-commands`),
права — `dontAsk` с разрешёнными MCP, чтение — только каталоги навыка, токены моста — запрет чтения.

## Поставить на сервер
```sh
uv run mcp/gm/gm.py init ~/airstrike-server/gm      # каталог сервера: config.toml, skill/, evals/, git
$EDITOR ~/airstrike-server/gm/config.toml            # мост, тестовый мост, владельцы, языки игроков, удары
uv run mcp/gm/gate.py --config ~/airstrike-server/gm/config.toml evals   # набор на голосе: выбрать модель
cp mcp/gm/systemd/gm.service ~/.config/systemd/user/ && systemctl --user enable --now gm
```
Тестовый сервер (`test_bridge`) — копия мира на своём порту: на нём наставник пробует рецепты; без него рецепты не
учатся (знания и правила — учатся). Люди: `gm.py tasks`, `gm.py log --last 50`, `gm.py recipes`,
`gm.py run <рецепт> '{…}' [--test]`.

## Охраняемые зоны — `zones.py`
Зона — круг на карте (x, z, радиус в блоках), куда удары, взрывы и полёты ведущего не должны попадать: стоянка
кораблей и самолётов игроков, база, место, где игроки собрались смотреть. Файл зон — `zones.json` каталога
сервера (`GM_ZONES`); общий для всех сессий, запись под flock. Сессии ставят и проверяют зоны инструментом `zones`,
охрана сверяет с ними каждый удар сама (`guard.strike` в config.toml). Удар в правиле игры (залпы шоу) идёт без
сессии: такое правило — только с именем, его скрипт охрана запоминает, а диспетчер сверяет снова при каждой
правке зон (и раз в минуту) и снимает правило, если новая зона на пути, — голос говорит об этом игроку.

```sh
python3 mcp/gm/zones.py add аэропорт -1650 470 250 --note "лайнер и NagaAI"   # корабль передвинули — та же команда
python3 mcp/gm/zones.py add зрители 120 -40 60 --ttl 30                         # на полчаса
python3 mcp/gm/zones.py check --from -2450 666 --to 52 118 --spread 50          # путь залпа и разброс у цели
```
`check` — код 0 («можно») или 1 («НЕЛЬЗЯ» с причиной и точкой обхода `--via`). Путь — отрезки от места пуска через
точки `via` к цели; у последнего отрезка запас растёт к разбросу цели. Запас по умолчанию 64 блока.

## Проверки
`python3 -m unittest discover -s mcp/gm/tests` (CI — на каждый PR): охрана (речь, запреты, владелец, удары и зоны,
скрипты, участки Sable, правка файлов, хук как процесс), рецепты, очередь, ворота, роли и весь путь с заглушками
моста и claude — сообщение → ход голоса → задача → исполнитель → итог голосу, и урок → ворота → навык.
Флаги и хуки Claude Code — по https://code.claude.com/docs/en/cli-reference, …/hooks, …/permissions.
